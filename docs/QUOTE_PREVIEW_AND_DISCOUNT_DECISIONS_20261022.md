# 報價表單、列印及成交前流程決定 — 2026-10-22

## 客戶及住宅地址

Sales填寫：地區、街道、屋苑／大廈、座數、樓層及單位。系統即時自動組合「完整工程地址」，唯讀顯示，不讓Sales另行輸入一個可能與分欄不一致的地址。

## 折扣

報價摘要可選：原價、95折、自訂折扣（填折後百分比）、自訂扣減（填港幣金額）。例如工程小計 HK$15,500，自訂扣減 HK$500，成交額為 HK$15,000。系統保存折扣模式、用戶輸入值與最終成交額；折後低於95%原價只顯示佣金提示，不硬性禁止。

## 兩個儲存動作

- **儲存草稿**：保存現時輸入，留在編輯工作，不進入客戶成交步驟。
- **前往預覽及成交**：同樣先保存，但轉至報價詳情；Sales可準備列印、取得客簽、登記付款及提交Office。它不是「已提交Office」。

## 客戶紙本簽署的建議流程

1. Sales完成工程明細及報價金額，按「前往預覽及成交」。
2. 在「準備列印報價單」選擇簽署／列印日期及當日主管。
3. 系統生成並鎖定當前版本的正式報價號（示例：`QSHMM26100001`），再開啟列印預覽。
4. Sales在現場列印紙本給客戶簽署；客戶簽署後，Sales拍攝／掃描同一份紙本，回到同一報價上載。
5. 系統把已簽檔綁到該版本，Sales確認「客戶已簽」，再登記誠意金／首期及提交Office。

若未能同日完成簽署，或需改當日主管，Sales必須回到修改報價建立新版本，再重新準備／重新列印；系統不會覆寫已列印版本的報價號、主管或日期。

## 號碼範圍

- 正式報價號：列印前生成，以 `Q + 當日主管代號 + Sales代號 + 年月 + 四位月流水` 表示；例 `QSHMM26100001`。
- Invoice號：仍只在會計核足適用首期後由開單員產生，維持現有 `主管代號 + Sales代號 + 年月 + 四位全公司月流水`；例 `SHMM26100001`。
- 兩者是不同文件、不同流水，不能因為預覽報價而提早出Invoice。
